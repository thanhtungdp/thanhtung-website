# Plan: /hermes-coaching — Coaching 1:1 cho CEO không có thời gian

> **Mục tiêu:** Xây dựng trang `/hermes-coaching` — dịch vụ coaching 1:1 giúp CEO apply Hermes Agent mà không cần tự học, thông qua buổi gặp 90 phút/tuần với chuyên gia + hỗ trợ setup kỹ thuật.

---

## 1. Bối cảnh & Positioning

### Vấn đề trang /hermes giải quyết
Trang `/hermes` (self-serve) hướng tới CEO **có thời gian tự học** — 4 tuần, 3–4 giờ/tuần, video pre-recorded + workbook. Giá 999k.

### Vấn đề trang /hermes-coaching giải quyết
Nhiều CEO **không có thời gian tự học**. Họ muốn kết quả nhanh — muốn ai đó ngồi cạnh, nhìn business của mình, rồi setup agent chạy thật ngay trong buổi gặp. Họ không cần "học phương pháp" — họ cần **người làm cùng mình**.

### Positioning statement
> Hermes Self-serve = học phương pháp.
> Hermes Coaching = **có người làm cùng bạn.** Mỗi tuần 90 phút. Ra khỏi buổi là có agent chạy.

## 5. Logic thanh toán & mã code

### Tích hợp CheckOutModal (reuse hoàn toàn)

Trang `/hermes-coaching` sẽ **reuse** `CheckOutModal.tsx` — component đã có sẵn, chỉ cần truyền đúng `courseCode` tương ứng.

#### Cơ chế (đã hoạt động ở /hermes):

1. Form submit → dispatch `window` event `hermes:checkout` với payload:
   ```ts
   { phone, email, fullname, courseCode, qty, price }
   ```
2. `CheckOutModal` nhận event → POST `https://n8n.simplamo.com/webhook/david-create-transaction`
3. n8n webhook trả về `{ Id, QRPayment, Price, Qty }`
4. Modal hiển thị QR, poll `david-check-transaction` mỗi 3s
5. Payment success → redirect `/hermes-coaching-thanksyou`

#### Logic chọn courseCode theo gói:

```ts
// Trong form submit handler:
const planSelect = document.getElementById('signup-plan') as HTMLSelectElement;
const selectedPlan = planSelect.value;
const courseCode = selectedPlan.includes('4 buổi')
  ? 'HERMES-MINI-COACH-4'
  : 'HERMES-MINI-COACH-12';

window.dispatchEvent(
  new CustomEvent('hermes:checkout', {
    detail: { fullname, email, phone, courseCode, qty: 1 },
  }),
);
```

#### Cấu hình n8n webhook (backend):

Webhook `david-create-transaction` cần handle 2 courseCode mới:
- `HERMES-MINI-COACH-4` → Price: 12,000,000 VND
- `HERMES-MINI-COACH-12` → Price: 29,000,000 VND

> **Lưu ý:** Cần cấu hình mapping courseCode → price trong n8n workflow. Xác nhận với backend/n8n admin.
